# Audio Studio 更新日志

当前维护 **Windows 电脑版和网页版**。两端使用统一版本号，以下按平台列出用户可感知的变化。

## v0.2.0 — 2026-11-13

Windows 与 Web 功能更新；本版本不再提供 Android 安装包。

### Windows 电脑版

- 新增音乐分享（MP3）、语音小文件（Opus）、无损存档（FLAC）用途预设，选择后仍可调整参数。
- 批量任务支持文件名搜索、状态筛选和无匹配提示，便于定位待处理或失败任务。
- 修复“开始全部”不启动新导入文件、重复点击导致重复任务、准备期间取消仍可能执行的问题。
- 任务保留入队时的设置，修改其他文件不会改变已经等待或执行中的任务；失败任务不会阻塞后续队列。
- 修复合并时静音被加到文件末尾、片段淡出从错误位置开始的问题；源文件时长不足以定位淡出时会明确提示。
- 改善短音频完成反馈，以及输出文件自动避让重名后的校验。
- 增加应用内更新提示和下载进度；后续安装更新要求有效签名包。真实跨版本安装与重启仍需发行环境验收。

### 网页版

- 提供与电脑版相同的三种用途预设、可编辑批量参数、队列搜索和状态筛选。
- 修复“开始全部”、取消、重试、任务设置漂移和队列异常停滞，批量参数调整后可明确应用到全部文件。
- 修复合并静音间隔与逐段淡出位置，输出参数适配目标格式支持的采样率和声道。
- 修复拖入大型目录时只导入首批文件的问题；继续保留音频过滤和导入数量上限。
- 本地存储不可用时使用内存设置，避免启动失败；内存设置不承诺关闭页面后保留。
- 增加已部署新版本的更新提示，确认后切换缓存并刷新；网站服务器仍需先完成部署。
- 改善深浅主题工作台和手机浏览器的任务行布局，保留可读文件名与完整操作入口。

### 平台范围

- 只维护和构建 Windows 电脑版、网页版，移除 Android 工程及其构建、发布配置。
- 历史 Release 的平台和附件情况保留事实说明，不将停止维护等同于远程附件已删除。

## v0.1.0 — 2026-11-09

首个发布版本。Git 标签指向 [`60fda0d`](https://github.com/yuchen0x1/Audio-Studio/commit/60fda0de3d988cf48bf6764b6458bb07cb2269d6)，GitHub 发布时间为北京时间 2026-11-09 02:41。

### Windows 电脑版

- 提供基于本机 FFmpeg 的音频转换、批量任务、剪辑、合并、文件分析和标签编辑入口。
- 格式注册涵盖 MP3、WAV、FLAC、AAC、M4A、OGG、Opus、WMA、AIFF、APE、AC3、AMR-NB、ALAC；实际可转换格式取决于本机 FFmpeg 的编码器。
- 提供文件选择、任务进度、取消/重试、输出位置查看和本地转换记录。
- 提供简体中文 / English、深浅主题及默认编码与输出命名设置。
- 发布 Windows x64 的 EXE 与 MSI 安装包；运行音频功能需要本机 FFmpeg / FFprobe。

### 网页版

- 使用内置 FFmpeg.wasm 在浏览器本地处理音频，提供转换、批量、剪辑、合并、分析和元数据工具入口。
- 提供浏览器文件导入和转换结果下载，以及本地历史、主题、语言和编码参数设置。
- 发布包含音频内核的静态站点压缩包，由静态服务器托管运行。
